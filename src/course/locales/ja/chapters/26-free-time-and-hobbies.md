# CH26 — 余暇と趣味の言葉を選ぶ / Free Time and Hobbies

**この章でできるようになること:** 余暇の活動の名前を言い、あまりなじみのない活動もいくつか理解します。自分の興味に合う言葉を選びます。

<!-- source-heading: Study: Build your activity vocabulary -->
## 学ぶ：活動を表す言葉を増やす

**Free time** は、仕事や必要な役割などを果たす時間の外に、自分で使える時間です。**hobby** は、興味や楽しみのために取り組む活動です。同じ活動が、ある人には趣味で、別の人には仕事という場合もあります。自分の生活に役立つ言葉を選びます。すべての活動を好きになる必要はありません。

| 活動の言葉 | 意味や具体例 |
| --- | --- |
| Walking / running / hiking | 歩くこと／走ること／通常は屋外を長めに歩くことです。hikingでは遊歩道などを歩くことがよくあります。 |
| Biking / cycling | 自転車に乗ることです。**mountain biking** は、荒れた道で自転車に乗る活動です。舗装道路の外の経路を使うことがよくあります。 |
| Swimming / sailing | 水の中を泳ぐこと／帆で進む船に乗ることです。 |
| Camping / having a picnic | テントなどの一時的な場所を使い屋外で過ごすこと／屋外で食事をすることです。 |
| Skiing / snowboarding | スキー板で雪の上を移動すること／スノーボードで移動することです。 |
| Skateboarding / jumping rope | スケートボードに乗ること／自分で回す縄を跳ぶ、縄跳びです。 |
| Birdwatching / fishing | 鳥を観察すること／魚を釣ろうとすることです。 |
| Horseback riding / climbing | 馬に乗ること／岩、壁などの面を登ることです。 |

ほかに、**yoga**（ヨガ）、**tai chi**（太極拳）、**flying a kite**（たこを揚げること）、**going to an amusement park**（遊園地へ行くこと）、**taking children to a playground**（子どもを遊び場へ連れて行くこと）もあります。

少し専門的な活動では、**orienteering** は地図とコンパスを使って経路を進む活動です。**foraging** は、野生の食べ物などを探して集める活動です。ここでは活動を識別する名前を学びます。実際の行い方を指示しているわけではありません。

<!-- source-heading: Study: Games and making things -->
## 学ぶ：ゲームと、ものを作る活動

| 言葉 | 意味 |
| --- | --- |
| Board game | 盤を使うゲームです。チェスはその一例です。 |
| Cards | トランプなどのカード、またはそれを使ったゲームです。 |
| Jigsaw puzzle | 別々のピースを組み合わせ、一枚の絵にするパズルです。 |
| Gaming | ゲームをすることです。この場面では特にビデオゲームを指します。 |
| Darts | 小さい先のとがったダーツを的の盤に向けて投げる活動です。 |
| Dominoes | 印のある長方形の駒を使うゲームです。 |
| Painting / drawing | 絵の具で絵を描くこと／ペン、鉛筆などの線で絵を描くことです。 |
| Knitting / sewing | 糸と編み針を使って布を作る、編み物／縫い目で材料をつないだり直したりする、縫い物です。 |
| Pottery | 粘土からボウルなどの物を作る、陶芸です。 |
| Photography / gardening | 写真を撮る活動／植物を育て、世話をする活動です。 |

**Crafting** は手で物を作る活動を広く表します。**Baking**、つまりオーブンで焼く菓子やパンなどを作ることも趣味になります。物の名前では、**chessboard** はチェスの盤、**chess pieces** はその上で動かす駒です。

<!-- source-heading: Study: Entertainment and music -->
## 学ぶ：娯楽と音楽

**movie theater** は映画を上映する場所です。**theater** は、生の舞台公演を行う場所を指すこともあります。**concert** は音楽の演奏会です。**festival** は、組織された催しやその連続で、複数の公演を含むこともよくあります。**nightclub** は夜の娯楽のための場所で、音楽やダンスがよくあります。

**band** は演奏する人たちのグループです。**orchestra** は、より大きく組織された器楽のグループです。**choir** は歌う人たちのグループ、合唱団です。**Ballet** は舞踊の形の一つで、**opera** は舞台の劇に音楽と歌を合わせたものです。

音楽の呼び名には **pop**（ポップ）、**rock**（ロック）、**country**（カントリー）、**hip-hop**（ヒップホップ）、**dance music**（ダンス音楽）、**jazz**（ジャズ）、**classical music**（クラシック音楽）があります。**Bhangra** も出会うことがある名前で、パンジャーブの舞踊や音楽と結びついています。呼び名は重なることもあります。分類名で好みがうまく伝わらなければ、歌手や曲の名前を挙げられます。

短く活動を言うなら、**I play chess**（チェスをします）、**I go hiking**（ハイキングに行きます）、**I do yoga**（ヨガをします）、**I like gardening**（園芸が好きです）などを使います。よく使う組み合わせの例です。すべての活動が同じ動詞と組み合うという規則ではありません。第33章では、趣味についてさらに長い会話をします。

<!-- source-heading: Practice: Select and retrieve -->
## 練習：言葉を選び、思い出す

声に出すか、短い答えを書きます。必要な活動の説明はすべて上にあります。

1. 四つの手がかりから活動名を言います。自転車に乗ること、ピースを組み合わせて絵にすること、粘土でボウルを作ること、鳥を見ることです。そのあと表の対応する行で確かめます。
2. 違うグループから活動を三つ選びます。上で示された組み合わせ、または **I like…** を使い、一つにつき短い文を一つ言います。
3. 架空の役として、ハイキングコース、陶芸の教室、チェスのクラブから一つを選びます。選んだ活動を簡単な言葉で説明します。**I'd choose…**（私なら…を選びます）、**You…**（そこでは…します）、**It involves…**（…をする活動です）が使えます。
4. 役の好みを変えます。屋外の活動を望んでいた人が、今は屋内の活動を望んでいます。別の活動を選び、何が変わったかを伝えます。
5. 表を閉じ、もの作りの活動を二つ、屋外の活動を二つ、公演を一つ言います。忘れた言葉は表に戻って確認し、説明をそのまま写さずにその意味を言ってください。

<!-- source-heading: Sample possibilities -->
### 解答例とその意味

1. **Biking or cycling; a jigsaw puzzle; pottery; birdwatching.**  
   自転車、ジグソーパズル、陶芸、鳥の観察です。
2. **I play chess. I go hiking. I like photography.**  
   チェスをする、ハイキングに行く、写真が好き、と三つの活動を言います。
3. **I'd choose the pottery workshop. You make things from clay.**  
   陶芸の教室を選び、粘土から物を作る活動だと説明します。
4. **I'd choose chess instead. I want an indoor activity today.**  
   今日は屋内の活動がよいので、代わりにチェスを選びます。
5. **Knitting and painting; swimming and camping; a concert.**  
   編み物と絵を描くこと、水泳とキャンプ、音楽の演奏会です。表のほかの活動を選んでも条件に合います。

**確認:** 活動名は説明された活動と合っていましたか。少数の言葉を、意味のある文で使えましたか。選択を変えたとき、新しい好みに合うものを選べましたか。
