## 1. Constructive Editorial SVG System (`IeltsStudyDiagrams.jsx`)

Unlike flashcard pictures (which hide words), **IELTS technical study diagrams teach data literacy, spatial orientation, logical trees, and structural blueprints**. Clean axis scales, stage labels, compass letters, and callout tags are essential — provided they follow strict geometric and typographic discipline.

### 1.1 Universal SVG Engineering Laws
1. **Standard Responsive Stage:**
   - Default `viewBox="0 0 720 H"` (where `H` is `200` to `420` depending on content; never taller than `440` so a diagram fits comfortably inside one laptop viewport).
   - Set `width="100%"`, `style={{ height: 'auto', display: 'block' }}`, `role="img"`, and `aria-label={alt}`.
   - Wrap every `<svg>` inside `<figure className="ies-diagram">` with `<figcaption>` rendering `title` + `caption` (including `"Practice data, invented."` whenever numerical/map data is shown).
2. **Strict Artico IELTS Palette Tokens (No `#000000`, No Neon RGB, No Gradients):**
   - Canvas / Card background: `#ffffff` with `1px` outer border `#dfe3e2` (`rx="10"`) or warm paper `#fbfaf7` for inset zones.
   - Primary ink & main lines: `#263b3b` (`strokeWidth="2"` for primary data/arrows, `"1.5"` for boxes).
   - Muted ink & gridlines: `#657273` for secondary text; `#e2e6e5` (`strokeDasharray="4 4"`) for chart gridlines.
   - Primary Academic / Supported / Focus Blue: `#285bcc` stroke/fill, `#eaf0fc` soft tint fill.
   - Secondary Series / Neutral Slate: `#5c6f7e` stroke, `#eef2f5` tint fill.
   - Trap / Warning / Rejected / Cancelled Amber-Rust: `#b84a14` stroke/text, `#fff6ee` tint fill, `#e5b899` border.
   - Verified / Positive / Preserved Botanical Green: `#275d3c` stroke/text, `#eef7f1` tint fill, `#b6d9c2` border.
   - General Training (`[GT]`) Accent: `#4a3f6b` stroke/text, `#f3f1f9` tint fill.
3. **Typography & Zero-Collision Layout Rules:**
   - Always set `fontFamily="inherit"` on `<svg>` so text uses Artico's loaded sans stack cleanly.
   - Minimum `fontSize="12"` (`11` only for minor axis ticks) on a `720`-wide `viewBox` — so text remains readable (`≥ 8.5px` physical) even on a `360px` phone screen!
   - **Never let text touch a box border or arrow:** leave at least `14px` horizontal padding and `10px` vertical padding inside every rect; compute box widths generously (`chars * 7.2 + 28`).
   - Define reusable `<marker id="arrow-ink">` and `<marker id="arrow-blue">` inside `<defs>` (using unique per-diagram ID prefixes like `d01-arrow` so multiple SVGs in SSR/DOM never collide on `<defs>` IDs!).

## 2. Audio & Media Slot System (`src/web/ielts-study/mediaManifest.js`)

### 2.1 Policy for This Release
1. **Do NOT generate new TTS/WAV files or call external audio/image APIs right now.**
2. **Reuse the 2 existing committed audio files** (`public/audio/ielts/workshop.wav` and `public/audio/ielts/speaking-example.wav`) as `status: 'ready'` where they fit naturally (`slot-l-correction` and `slot-s-part1-direct`).
3. **Define the remaining 8 teaching audio slots as `status: 'reserved'`** in `mediaManifest.js` with **complete, publication-ready original scripts, speaker labels, stress/pause annotations, and `teachingFocus` notes**.
4. **How `<MediaSlotBlock slotId="..." />` Renders:**
   - Every slot renders a clean `<aside className="ies-media-slot" data-media-slot={slot.id} data-media-status={slot.status}>`.
   - **Header row:** Ear or Microphone `CurriculumIcon` + `slot.title` + metadata badge (`slot.status === 'ready' ? 'Audio example' : 'Audio script · Recording slot reserved'` + `slot.durationLabel` + `slot.voices`).
   - **Teaching Focus strip:** 1–2 crisp ASE sentences stating *what to listen for / observe in the wording*.
   - **Audio Player (when `slot.status === 'ready'`):** `<audio controls preload="none" src={import.meta.env.BASE_URL + slot.src} />` + honest provenance caption (`"Original Artico training recording · synthetic voice, not an official test or band sample."`).
   - **Annotated Spoken Script (always accessible; open by default when `status === 'reserved'`, inside `<details>` toggle when `status === 'ready'` so learners can listen before reading if they wish):** Renders speaker turns with `==signal/stress highlights==` and `[discourse notes]` so the page teaches 100% of the concept immediately without looking broken or unfinished!
