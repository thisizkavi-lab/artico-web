# CH30 — ジムで入会やクラスについて聞く / At the Gym

**この章でできるようになること:** 会員制度とクラスについて質問し、入会するかを決めます。初めて利用するときに、必要な説明や手助けを求めます。

<!-- source-heading: Study -->
## 学ぶ

<!-- source-heading: Choose the activity you mean -->
### どの活動について話すかを選ぶ

| 言葉・表現 | この場面での意味 |
| --- | --- |
| **work out / a workout** | 運動すること／一回の運動の時間や内容です。前者は動作、後者は名詞です。 |
| **weight training** | 重りを抵抗として使う運動です。 |
| **personal trainer** | 一人の人の運動練習を指導する人です。 |
| **fitness class / instructor** | 集団で運動するクラス／そのクラスを指導する人です。 |
| **spin class / indoor cycling** | 固定式の運動用自転車を使うクラスです。 |
| **yoga** | 姿勢、動き、呼吸を使う活動です。 |
| **Pilates** | マットや専用の器具で、制御した動きを使う方法です。 |
| **HIIT** | 強度の高い運動の時間と、回復のための時間を交互に置く、高強度インターバルトレーニングです。 |
| **dance class** | ダンスの動きを学んだり練習したりするクラスです。 |

クラス名は、その活動について尋ねるために使えます。名前だけから内容を推測せず、**What does this class involve?**（このクラスではどんなことをしますか）や **Is there a class for beginners?**（初心者向けのクラスはありますか）と聞けば、担当者にその回の内容を説明してもらえます。

<!-- source-heading: Ask about the membership -->
### 会員制度について尋ねる

この章では、次の架空のジムの情報を使います。

| Choice | Practice conditions | 日本語の説明 |
| --- | --- | --- |
| Day pass | $10; gym access for that day; classes cost extra. | その日だけ使える利用券は$10です。クラスには追加料金がかかります。 |
| Monthly membership | $40 each month; no joining fee; gym access and cycling classes included; renews automatically. | 月会費は$40で、入会金はありません。ジムと自転車のクラスを利用でき、自動更新されます。 |
| Yoga class | $6 per class, including for monthly members. | ヨガは一回$6です。月会員でもこの料金がかかります。 |
| Personal training | Available by separate appointment; ask staff for the price. | 別に予約すれば利用できます。価格はスタッフに確認します。 |

For this monthly plan, staff require a cancellation request at least seven days before the next renewal. This is a scene condition, not a rule for all gyms.  
この月会員の設定では、次回の更新前に解約するため、少なくとも7日前までに申し出が必要です。この場面の条件で、すべてのジムの規則ではありません。

**Renewal** は会員制度の継続です。**automatic** な更新は、毎月新たに購入を申し込まなくても、決めた取り扱いによって更新が行われることです。

**Visitor:** Hi. I'm interested in joining. Could you explain the membership options?  
**Staff:** A day pass is ten dollars. Monthly membership is forty, with no joining fee.  
**Visitor:** Are classes included?  
**Staff:** Cycling is included in the monthly plan. Yoga is six dollars per class.  
**Visitor:** Does the monthly plan renew automatically?  
**Staff:** Yes. To cancel before a renewal, we need your request at least seven days beforehand.  
**Visitor:** Could I have those terms in writing before I decide?  
**Staff:** Of course.  

訪問者は入会に関心があり、選択肢の説明を頼みます。料金を聞いたあと、クラスが含まれるか、自動更新されるかを確かめます。スタッフは、自転車のクラスは含まれ、ヨガは一回$6と説明します。解約の申し出は更新の少なくとも7日前という条件です。訪問者は、決める前にその条件を書面でもらいたいと伝えています。

**Included** は提示された料金に含まれるという意味、**Extra** は追加で必要という意味です。**Is there a joining fee?** は入会金の有無、**How do I cancel?** は解約方法、**Can I pause the membership?** は会員の利用を一時停止できるかを聞きます。一つの答えで三つ全部がわかるわけではありません。

ほかに、**Could I have a tour?**（中を案内してもらえますか）、**Where are the locker rooms?**（更衣室はどこですか）、**Can I book a personal trainer?**（個別のトレーナーを予約できますか）、**Do you offer women-only sessions?**（女性だけが参加する回はありますか）と聞けます。スタッフが有無と条件を説明します。この架空の情報カードには最後の質問への答えがないので、あるともないとも決めずにおきます。

<!-- source-heading: Decide without being pushed into agreement -->
### 自分の意図に合う選択を伝える

**Staff:** Would you like to sign up today?  
**Visitor:** I'd like to try a day pass first.  
**Staff:** Sure. Would you like a class as well?  
**Visitor:** Not today. Just the day pass, please.  

スタッフは今日入会するか聞きます。訪問者は、まず一日利用券を試したいと答えます。クラスも勧められますが、今日は利用券だけにすると伝えています。

**Sign up** は登録する、入会するという意味です。**I'd like to join** は入会するという肯定的な決定です。**I'm just looking today**（今日は見ているだけです）や **I don't want to sign up today**（今日は入会しません）は別の意図を表します。

選択肢を比べる時間がほしければ **I'll think about it and get back to you.**（考えてから、改めて連絡します）と言えます。これは、入会が確定したという返事ではありません。

<!-- source-heading: Attend a first class -->
### 初めてクラスに参加する

**Participant:** Hi. I'm here for the cycling class. It's my first time.  
**Instructor:** Welcome. We'll use bike five for you today.  
**Participant:** Could you show me how to adjust it?  
**Instructor:** Yes, I'll show you before we start.  
**Participant:** And how should I let you know if I need a break?  
**Instructor:** Just tell me.  

参加者は自転車のクラスに初めて来たと伝えます。指導者は今日使う自転車を5番にし、調節方法は始める前に見せると答えます。参加者は休憩が必要なときの伝え方も聞き、言ってくれればよいと確認します。

**It's my first time** は初めてだと伝え、説明が必要なことを知らせます。**Could you repeat that more slowly?** は「もう少しゆっくり繰り返してもらえますか」という聞き直しです。**I need a break** は休憩が必要なこと、**I'd like to watch first** はまず見学したいという希望です。この章はコミュニケーションの選択肢を扱っています。運動の実施方法の指示ではありません。

ほかの参加者と **Have you taken this class before? — A few times.** と話せば、「このクラスを受けたことはありますか」「何回かあります」という会話になります。相手の経験から話は始められますが、その経験だけで、自分にもそのクラスが合っていると確定するわけではありません。

<!-- source-heading: Practice -->
## 練習

ジムの情報カードを使います。一人の場合はスタッフや指導者の発話も言ってから、自分の返事をします。相手がいる場合は役を交代します。

1. 月会費、入会金、自転車のクラス、ヨガについて聞きます。スタッフの役では、カードにある情報だけで答えます。どのクラスが追加料金か確認します。
2. 更新前に解約する方法を聞きます。スタッフは7日前という条件を答えます。その条件を繰り返し、書面でもらうよう頼みます。
3. スタッフが入会したいか聞きます。月会員、一日利用券、購入しない、のどれかを選び、はっきり伝えます。
4. 初めての自転車のクラスに来て、自転車の調節方法を聞きます。そのあと、指示を理解できなかった場面に変え、繰り返しを頼みます。
5. 個別トレーニングを予約したいものの、価格はわかりません。答えを作らずに、費用と予約できる時間を聞きます。

**Possible responses:** “So cycling is included, but yoga is six dollars extra?” / “You need the cancellation request at least seven days before renewal. Could I have that in writing?” / “Just a day pass today, please.” / “Could you repeat the instruction more slowly?” / “What does a personal-training session cost, and when could I book one?”  

順に、自転車は料金内でヨガは$6の追加だと確認する返事、更新の少なくとも7日前の解約申し出が必要だと繰り返して書面を求める返事、今日は一日利用券だけにする返事、ゆっくりした繰り返しを頼む質問、個別トレーニングの料金と予約できる時間を聞く質問です。

あとで見本を隠し、クラスや入会するかどうかの選択を変えて練習します。**確認:** 会員制度、追加料金、まだ答えが出ていない質問、自分が実際に選んだことを区別できましたか。わかったふりをせず、必要な説明を求められましたか。
