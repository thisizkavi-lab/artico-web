# Vocabulary lesson visual assets

- The flag SVGs in `flags/` are from [flag-icons](https://github.com/lipis/flag-icons), version 7.3.2, by Panayiotis Lipiridis and contributors, under the MIT license in `flags/LICENSE`.
- `world-land.svg` was generated from the public-domain [Natural Earth 1:110m land data](https://www.naturalearthdata.com/about/terms-of-use/). It is a decorative, simplified overview rather than a political-boundary map.
