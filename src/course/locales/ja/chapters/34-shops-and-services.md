# CH34 — 店とサービスの語彙 / Shops and Services

**この章でできるようになること:** 役に立つ店や施設の名前、支払いの言葉を理解し、必要な言葉を選んで自分の用件を伝えられるようになります。

<!-- source-heading: Study -->
## 学習

ここにある言葉は、第35〜44章の店やサービスでの会話につながります。まず、自分が利用しそうな場所から覚えましょう。この一覧は、必要なときに参照するためのものです。全部を暗記できるかを試すものではありません。

| 場所を表す英語 | どのような場所か |
| --- | --- |
| grocery store / supermarket | 食料品や日常の生活用品を売る店です。 |
| convenience store | 比較的小さく、さまざまな日用品を扱う店です。 |
| hardware store | 工具や、家で行う作業の材料・用品を売る店です。 |
| garden center | 植物や園芸用品を売る場所です。 |
| gas station | 車などに燃料を入れられる場所です。 |
| shopping mall | 一つの商業施設に複数の店が集まっている場所です。 |
| pharmacy | 薬について尋ねたり、薬を受け取ったり購入したりする場所です。 |
| post office | 郵便のサービスを扱う場所です。 |
| library | 本や、ほかの情報資料を提供する場所です。 |
| bank | 金融のサービスを提供する事業者です。 |

ほかにも、目的に応じて次の店名が役立ちます。

- **bakery**：パンや焼き菓子の店です。
- **butcher shop**：肉の店です。
- **florist**：花の店です。
- **bookstore**：本の店です。
- **shoe store**：靴などを売る店です。
- **hair salon**、**barbershop**：髪を切るなど、髪に関するサービスを受ける店です。

店の名前だけで、売っているものの範囲がすべて分かるとは限りません。分からないときは、欲しいものを扱っているか尋ねましょう。

<!-- source-heading: People and places inside -->
### 店内にいる人と場所

**customer** は、商品を買ったりサービスを利用したりする客です。**cashier** は会計を担当する人です。**sales associate** は店内で客を手伝う店員です。誰に何を頼むかを考えるときに使えます。

**Checkout** は、代金を支払う場所、または支払いの手続きそのものを指します。**aisle** は棚と棚の間の通路です。**line** は順番を待つ人の列です。たとえば **Is this the line for checkout?** なら、「これは会計を待つ列ですか」と確認できます。店内の通路と、人が待つ列を区別しましょう。

<!-- source-heading: Money and purchases -->
### お金と買い物

| 買い物で使う英語 | この場面での意味 |
| --- | --- |
| cash | 紙幣や硬貨など、現物のお金です。 |
| debit card | つながっている銀行や信用組合の口座のお金を使うカードです。 |
| credit card | 買い物の代金を借り、後で返済する形のカードです。 |
| receipt | 買い物や支払いの記録です。 |
| sale | 価格を下げて売る期間や、そのような販売の提示です。 |
| refund | 購入後に返されるお金、または返金です。 |
| exchange | 商品を別の商品に替えることです。 |
| ATM | 特定の銀行取引を行う機械です。 |
| contactless payment | 対応するカードや端末を読み取り機に近づけて行う支払いです。 |

**refund** はお金が返ること、**exchange** は商品を替えることです。どちらも「返品に関係する言葉」ですが、求める結果が違います。

単語は、よく使うまとまりでも練習しましょう。**pay for a jacket** はジャケットの代金を払うこと、**get a receipt** は購入や支払いの記録を受け取ること、**return an item** は商品を返品すること、**ask for a refund** は返金を求めることです。返金を尋ねたからといって、その店が必ず応じると決まるわけではありません。

**A:** I'm looking for a bookstore.  
**B:** There's one near the library.  
**A:** Thanks. And is there an ATM nearby?  
**B:** I don't know, but you could ask at the bank.  

Aは本屋を探していると伝えています。Bは図書館の近くにあると答えます。続いてAは近くにATMがあるかを聞きます。Bは場所を知らないので、銀行で尋ねるという方法を提案しています。**I'm looking for...** の後に探している場所を置くと、用件がはっきりします。

<!-- source-heading: Practice -->
## 練習

1. 次の用件に合う場所を選び、**I'm looking for...** を使って答えてください。用件は、**a loaf of bread**（パン一つ）、**a hammer**（金づち）、**a haircut**（散髪）、**information about mailing a box**（箱を郵送するための情報）です。
2. 次の意味に合う言葉を選んでください。購入の記録、お金が返されること、順番を待つ人々、棚の間の通路です。
3. 次の架空の案内一覧を使います：**Pine Bakery, Lake Hardware, Oak Pharmacy, West Post Office**。**nails**（くぎ）、**bread**（パン）、**mailing help**（郵送についての手助け）を求めるなら、どこへ行けばよいか尋ねてください。一人なら、尋ねる役と答える役の両方を行います。

**答えの例:** “I'm looking for a bakery / hardware store / hair salon / post office.” 語彙問題の答えは **receipt, refund, line, aisle** です。“Where can I buy nails?” — “Try Lake Hardware.”  

最初の例は、必要なものやサービスに合う店を選んでいます。最後の会話は、くぎを買える場所を聞き、架空の一覧にある店を勧めるやり取りです。

後で一覧を隠し、役立つ言葉を三つ使って一つの用件を説明してください。相手が、行きたい場所や必要なものを判断できるかを確認しましょう。すべての項目を覚えている必要はありません。
