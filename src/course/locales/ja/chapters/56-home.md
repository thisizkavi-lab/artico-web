# CH56 — 住まいの言葉 / Home

**この章でできるようになること:** 住居、部屋、家具について必要な語を理解し、場所や必要な物を説明できます。

<!-- source-heading: Study -->
## 学習

この語彙は、第57章から第64章の助けになります。自分の住まい、または練習の住まいを一つ選び、必要な言葉から始めます。ほかの語は、必要なときに参照してください。

<!-- source-heading: Types of homes and areas -->
### 住居の種類と周囲の場所

**apartment** は、ほかの区画や住居も入っている建物の中の住まいです。**house** は、住居としての建物です。**duplex** は、この章で使う米国の住居の意味では、二つの住まいに分かれた建物を指すことがあります。**townhouse** は、列になったほかの家とつながる家です。**cabin** は、小さく、簡素なことが多い家で、田園の地域や休暇を過ごす場所などと結び付く語です。

**neighborhood** は、周囲の近隣地域です。**Upstairs** と **downstairs** は、上の階と下の階を表します。**basement** は、全体または一部が地面より下にある場所です。米国の建物の階の数え方では、**first floor** は通常、地面の高さにある階を指します。ただし、どの数え方も同じとは考えず、その建物の表示を確認します。

<!-- source-heading: Rooms and parts -->
### 部屋と住まいの部分

| 英語 | 意味 |
| --- | --- |
| bedroom | 寝るための部屋、寝室です。 |
| bathroom | トイレと洗面台がある部屋です。浴槽やシャワーもあることが多いです。 |
| kitchen | 食事を作る場所、台所です。 |
| living room | くつろいだり、一緒に時間を過ごしたりする共用の部屋です。 |
| dining room | 食事に使う部屋です。 |
| hallway | 部屋どうしをつなぐ通路、廊下です。 |
| laundry room | 衣類を洗う場所です。 |
| garage | 車を置く場所、またはほかの収納に使う場所です。 |
| balcony | 建物に付いた、屋外の張り出した場所です。 |
| yard | 家の脇や周りにある、屋外の土地です。 |

**Roof** は屋根、**fence** は柵、**stairs** は階段、**front door** は玄関のドアです。**home office** は、家で働くために使う場所です。場所を伝えたり、何を直したいか説明したりするときに役立ちます。

<!-- source-heading: Appliances and furniture -->
### 家電と家具

**Refrigerator** は食品を冷たく保つ冷蔵庫で、**fridge** ともよく呼びます。**freezer** は、食品を凍らせる冷凍庫です。**oven** は、熱で食品を調理するオーブンです。**washing machine** は、衣類を洗う洗濯機です。**dishwasher** は、食器を洗う機械です。**sink** は、水を使える設備のある流しや洗面の器です。

家具の語も確認します。

- **bed** はベッドです。**crib** は、赤ちゃんのためのベッドです。
- **dresser** は、引き出しのある収納家具です。**closet** は、収納のための場所や収納設備です。
- **sofa** はソファ、**armchair** は肘掛けのある椅子です。
- **coffee table** は、くつろぐ場所などに置く低いテーブルです。
- **bookshelf** は本棚、**dining table** は食事のためのテーブルです。
- **wardrobe** は、独立して置く衣類収納の家具を指すことがあります。名前だけで相手に伝わらなければ、物を説明します。

家の作業を説明する言葉の組み合わせには、**paint the wall**「壁を塗る」、**repair the fence**「柵を直す」、**put up shelves**「棚を取り付ける」、**replace the carpet**「カーペットを交換する」、**remove the wallpaper**「壁紙を取り除く」があります。第38章と第61章で、頼みたい仕事を説明するときに使えます。

<!-- source-heading: Practice -->
## 練習

1. 次の意味に合う語を答えます。地面より下の場所、部屋どうしの通路、衣類のための家電、引き出しのある家具です。
2. 練習の住まいを、次の設定で説明します。 **apartment; one bedroom; kitchen and living room; balcony; no garage.** 寝室が一つあり、台所、くつろぐ部屋、バルコニーがあり、車庫はない住まいです。三つの文で説明してください。
3. 寝室または台所に必要な物を三つ選びます。それぞれ何に使うかを説明してください。
4. **We need someone to...** と、上の作業の組み合わせを一つ使い、家の作業を人に頼みたいと伝えます。

<!-- source-label: Sample possibilities: -->
**返答例:** **Basement, hallway, washing machine, dresser.** “It's a one-bedroom apartment. It has a kitchen and a living room. There's a balcony, but no garage.” / “We need someone to repair the fence.”  

最初の四語は、意味から語を選ぶ練習の答えです。住まいの説明では、寝室が一つのapartmentで、台所と居間、バルコニーがあり、車庫はないと伝えています。最後の文は、柵を直す人が必要だという依頼です。

後で一覧を隠し、選んだ言葉で同じ住まいを説明してください。丸暗記した一覧だけに頼らず、部屋、家電、家具を区別して使えたかを確認します。
