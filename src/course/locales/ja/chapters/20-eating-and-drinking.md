# CH20 — 食事と飲み物の言葉を使う / Eating and Drinking

**この章でできるようになること:** 注文や料理など、したいことに必要な飲み物、道具、調理方法、メニューの言葉を選び、思い出して使います。

<!-- source-heading: Study: Drinks and additions -->
## 学ぶ：飲み物と、加えるもの

全部を一度に覚える必要はありません。何を注文したいかに合わせて、必要な言葉を探します。

| 言葉・表現 | 意味 |
| --- | --- |
| **black coffee** | 牛乳やクリームを加えていないコーヒーです。 |
| **coffee with milk / cream** | 牛乳入り、またはクリーム入りのコーヒーです。加えてほしいものを指定します。 |
| **espresso** | 挽いたコーヒーに熱い湯を圧力で通して作る、濃いコーヒーです。 |
| **latte / cappuccino** | エスプレッソに牛乳を合わせた飲み物です。cappuccinoには牛乳の泡の層があります。作り方は店などによって異なります。 |
| **iced coffee / iced tea** | 冷やして出すコーヒー、紅茶です。通常は氷が入ります。 |
| **herbal tea** | ハーブなどの植物の材料を湯に浸して作る飲み物です。 |
| **hot chocolate / milkshake** | 温かいチョコレートの飲み物／通常は牛乳とアイスクリームなどを混ぜて作る、冷たく、とろみのある飲み物です。 |
| **juice / soda / sparkling water** | 果物や野菜の汁／清涼飲料、通常は炭酸飲料／炭酸が入った水です。 |
| **whole milk / skim milk** | 脂肪の含有量が異なる牛乳の種類です。skim milkは脂肪の大部分を取り除いた牛乳です。 |
| **oat milk / soy milk / almond milk** | オーツ麦、大豆、アーモンドなど、材料の植物名がついた飲み物です。 |
| **reusable cup** | 繰り返し使うために作られたカップです。 |

**No sugar** は「砂糖なし」、**with milk** は「牛乳入り」、**without ice** は「氷なし」です。注文に詳しい希望を加えます。第21章では、これらを会話全体の中で練習します。

<!-- source-heading: Study: Tools and actions -->
## 学ぶ：道具と動作

| 道具 | 動作や用途 |
| --- | --- |
| **knife; cutting board** | 包丁とまな板です。**Slice** は薄く切ること、**chop** はまな板の上などで細かく、または小さな部分に切ることです。 |
| **peeler; grater** | 皮むき器とおろし器です。**Peel** は皮をむくこと、**grate** は細かな断片になるようにおろすことです。 |
| **mixing bowl; spoon** | 材料を混ぜるボウルとスプーンです。**Mix** は材料を混ぜること、**stir** は円を描くようにかき混ぜることです。 |
| **whisk** | 泡立て器です。針金状の道具で材料をかき混ぜたり、泡立てたりします。道具の名前にも動作の言葉にもなります。 |
| **measuring cup; kitchen scale** | 計量カップと料理用のはかりです。前者は容量を量り、後者は材料の重さを量ります。 |
| **colander; strainer** | 水切り用のざると、液体をこす道具です。液体と固形物を分けたり、水を切ったりします。colanderは穴のあるボウル状の道具です。 |
| **skillet / frying pan; saucepan** | 比較的浅いフライパンと、液体やほかの食材を調理するための深めの鍋です。 |
| **blender; mixer** | 刃で食材を細かく混ぜる機械と、材料を混ぜ合わせる機械です。 |
| **baking dish; microwave; toaster** | オーブンに入れる耐熱皿、食べ物を温める電子レンジ、パンを焼くトースターです。 |
| **French press** | 押し下げる部品でコーヒーの粉と飲み物を分ける、コーヒー用の器具です。 |

ほかに使える動作として、**pour** は液体を容器などへ注ぐこと、**roll out** は生地を延ばして平らにすること、**burn** は熱を加えすぎて食べ物を焦がすことです。ここでは言葉の意味を学んでいます。料理を完成させるためのレシピ全体ではありません。

<!-- source-heading: Study: Preparation words on a menu -->
## 学ぶ：メニューに出てくる調理方法

- **Baked** と **roasted** は、オーブンで加熱したことを表します。
- **Grilled** は、グリルで焼いたことを表します。**broiled** は、たとえばオーブン上部のブロイラーなどからの直接の放射熱で加熱したことを表します。
- **Fried** は熱い油や脂で調理したという意味です。**Stir-fried** は、少量の油を使った鍋などで、食材を動かしながら短時間で炒めたことです。**Deep-fried** は、熱い油や脂に浸して揚げたことです。
- **Boiled** は沸騰した液体でゆでたことです。**poached** は液体で穏やかに加熱したこと、**stewed** は液体でゆっくり煮込んだこと、**steamed** は蒸気で蒸したことです。
- **Marinated** は、食材を味のついた液体に漬けておいたことです。**Smoked** は煙を使って加工したことを表します。

すべての調理方法を知らなくても、**Is it baked or fried?**（これはオーブンで焼いたものですか、それとも油で調理したものですか）と聞けます。第25章では、レシピを話したり、協力して調理したりする表現を学びます。

<!-- source-heading: Study: Eating out -->
## 学ぶ：外食で使う言葉

- **Appetizer / starter:** 最初に出る料理、前菜です。
- **Main course / entrée:** 食事の中心となる料理です。entréeがこの意味で使われるのは、米国のレストランでの用法です。
- **Side / side dish:** 別の料理に添えて出される料理です。
- **Dessert:** 甘い料理や、食後の甘い一品です。**Pudding** は特定のデザートを指すことがあり、すべてのデザートを指すとは限りません。
- **Reservation:** テーブルなどの場所を確保するための予約です。
- **Check / bill:** レストランで、支払う金額を示す伝票です。
- **Split the check:** 支払いを複数の人で分けることです。

**Vegetarian** は肉と魚を含まない食べ物、**vegan** は動物由来の材料を含まない食べ物を表します。**Dairy-free** は乳製品を避けたことを表します。

**Gluten-free** は、グルテンを含まない、または適用される表示基準の限度より少ない食品を表します。グルテンは小麦、大麦、ライ麦に含まれるたんぱく質の一群です。これらの表示はそれぞれ異なる条件を表しています。gluten-freeだからといって、すべてのアレルゲンがないという意味にはなりません。材料や調理方法が重要な場合は、実際の内容を尋ねます。その質問は第24章で扱います。

## 練習：必要な言葉を選び、思い出す

この架空の注文を使います。**An iced tea with no sugar; baked vegetables as the main dish; a side of rice; fruit for dessert.**  
砂糖なしのアイスティー、主菜としてオーブンで焼いた野菜、付け合わせのご飯、デザートの果物、という設定です。

1. 飲み物、調理方法、主菜、付け合わせ、デザートに当たる部分をそれぞれ見つけます。自分の言葉で注文を言ってください。
2. 言葉を使う三つの課題に合う道具を選びます。リンゴを薄く切る、粉の重さを量る、パスタの水を切る、という課題です。**I'd use...**（私なら…を使います）で選択を説明します。
3. 客が **Is it baked or fried?** と尋ねます。この場面の設定はbakedです。正しい調理方法を答えてください。
4. カフェ、レストラン、キッチンで自分が実際に使いそうな言葉を5個選びます。意味の欄を隠して、それぞれの意味を見ずに説明します。
5. 選んだ少数の言葉だけを使い、短い注文か調理の説明を作ります。一つの詳細を変えて、もう一度言います。一人の場合は、**What would you like?**（何になさいますか）または **What do you need?**（何が必要ですか）を自分で尋ね、自分で答えてください。

<!-- source-heading: Sample possibilities -->
### 解答例とその意味

1. **I'd like an unsweetened iced tea, baked vegetables with a side of rice, and fruit for dessert.**  
   砂糖を加えていないアイスティー、焼いた野菜とご飯の付け合わせ、デザートの果物を注文しています。unsweetenedは甘味を加えていないという意味です。
2. **A knife and cutting board; a kitchen scale; a colander.**  
   順に、包丁とまな板、料理用のはかり、水切り用のざるです。それぞれ、薄く切る、重さを量る、水を切る、という課題に対応します。
3. **It's baked.**  
   オーブンで焼いたものだと答えています。

**確認:** 選んだ言葉は、伝えたい飲み物、道具、調理方法を示していましたか。長い一覧を繰り返すだけでなく、食事の場面で必要な少数の言葉を選び、思い出して使えましたか。
