# CH45 — 仕事と学習の語彙 / Work and Study

**この章でできるようになること:** 仕事、教育、雇用に関する言葉を必要に応じて選び、状況を説明したり質問したりできるようになります。

<!-- source-heading: Study -->
## 学習

自分の仕事や学習に関係する言葉を選びましょう。この章の語彙は第46〜55章の会話につながります。会話を始める前に、すべての職業名を暗記する必要はありません。

<!-- source-heading: People and jobs -->
### 人と仕事

| 英語の言葉 | どのような仕事か |
| --- | --- |
| server / chef | serverは食べ物を客に提供する人、chefは職業として料理を作る人です。 |
| receptionist | 来訪者を迎えたり、入ってくる問い合わせや依頼を受けたりする人です。 |
| teacher / librarian | teacherは教える人、librarianは図書館のサービスを専門の仕事として行う人です。 |
| doctor | 医療の場面では、病気を評価し、治療する医療専門職を指します。 |
| nurse | 患者のケアを行い、ケアを調整する医療専門職です。 |
| pharmacist | 薬を渡し、使い方を説明する専門職です。 |
| mechanic | 機械を修理する人です。車を扱う場合がよくあります。 |
| electrician / plumber | electricianは電気の設備、plumberは配管や水の設備を専門に扱う仕事です。 |
| accountant | 財務の記録や会計を扱う人です。 |
| engineer / architect | engineerは技術的な仕組み、architectは建物を設計する専門職です。 |
| real estate agent | 土地や建物など、不動産の取引を手伝う人です。 |
| freelancer | 顧客から独立した立場で仕事を受ける人です。 |

ほかにも、**lawyer**（法律を扱う専門職）、**dentist**（歯科医）、**veterinarian**（獣医）、**flight attendant**（航空機の客室で対応する乗務員）、**courier**（荷物などを届ける人）、**security guard**（警備員）、**firefighter**（消防士）、**app developer**（アプリを開発する人）、**childcare provider**（子どもの世話をする仕事の人）があります。

**I work as a receptionist** は、受付の仕事をしているという役割を説明します。**I'm studying engineering** は、工学を学んでいるという分野を説明します。職業と、学んでいる分野のどちらを話しているかに合わせて使えます。

<!-- source-heading: Education -->
### 教育と学習

**class** は、一回の授業を指すことも、その授業に参加する学生の集まりを指すこともあります。**course** は、ある科目やテーマを、組み立てられた学習を通じて学ぶ課程です。**lecture** は、教えたり説明したりするための講義です。この三つを同じ意味のものとして一括りにせず、場面を見て理解します。

**Homework** は、授業の外で行うよう出された学習です。**assignment** は、一つの具体的な課題です。**exam** または **test** は、学習の成果を確かめるものです。**Pass** は示された基準を満たすこと、**fail** はその基準を満たさないことです。

**degree** は、カレッジや大学の課程を修了して授与される学位です。**diploma** は、学習の修了を示す書類です。課程によっては、資格の名称としてもこの言葉を使います。**certificate** は、修了や特定の達成を記録したものです。ある講座のcertificateが何を証明するかは、具体的に尋ねます。名称だけで、複数の資格が同じ水準や意味だと決まるわけではありません。

**Graduation** は、学習の課程を修了すること、またはそれに関連する式を指します。**schedule** は予定された時間を示すものです。**Tuition** は、この教育の文脈では、授業や指導を受けるための料金を指します。

<!-- source-heading: Employment -->
### 雇用と働き方

**employer** は人を雇う側です。**employee** はその雇用者のために働く人です。似た形の言葉ですが、どちらの立場かが違います。

**Full-time** と **part-time** は、働く時間などの取り決めを表します。前者はその仕事で定める通常の勤務枠で働く形、後者はより短い時間で働く形を表す言葉です。具体的な仕事ではどのくらいの時間になるかを尋ねます。**Temporary** は、限られた期間を予定する仕事です。**permanent** は、継続する取り決めを表します。一生雇用が続くという保証を意味するわけではありません。

**shift** は、予定された一つの勤務時間帯です。**Overtime** は、関連する通常の時間、または定められた時間を超える仕事です。

給与については、言葉ごとの意味を区別します。**Wages** は、働いて得る賃金で、時間あたりの金額として話されることがよくあります。**salary** は、合意された定期的な給与額で、年額として示されることがよくあります。**Hourly pay** は、一時間あたりの支払いです。その仕事の給与がどのように計算されるかは、提示される雇用条件で確認します。

**pay stub** は、得た給与と、そこから差し引かれる金額が書かれた明細です。**Benefits** は、通常の給与以外に雇用で提供されるものです。**Paid time off** は、雇用者の取り決めに従い、仕事を休んでも給与が支払われる時間です。それぞれの内容は、その仕事の取り決めで確認します。

**Resign** は、自分の意思で仕事を辞めることです。**retire** は、人生の後の時期や職業上の決定として、働くことをやめることです。退職に関係する言葉でも、示す状況が違います。

## 練習

1. 自分の興味に合う言葉を四つ選び、それぞれの意味を自分の言葉で説明してください。
2. 次の意味に当たる言葉を選んでください。人を雇う組織、予定された勤務の時間帯、講座を受けるための料金、給与の記録です。
3. 次の架空の役の設定を使います：**part-time receptionist, studying accounting, Tuesday classes**。part-timeで受付の仕事をし、会計を学び、火曜日に授業があります。二つの文で説明し、その後で、その仕事の勤務時間を尋ねてください。

**答えの例:** **Employer, shift, tuition, pay stub.** “I work part-time as a receptionist. I'm studying accounting, with classes on Tuesdays. What hours does the job involve?”  

語彙問題では、雇う側、勤務の時間帯、授業料、給与明細をそれぞれ区別します。会話の例は、働き方と学習を伝え、仕事の具体的な時間を質問しています。**part-time** という言葉だけでは、その仕事の時間数はまだ分かりません。

後で一覧を隠し、自分が選んだ言葉だけを思い出して使ってください。関連する言葉を同じものとして扱わず、人、活動、資格、勤務条件を区別できるかを確認しましょう。
